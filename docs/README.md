# gh-qw documentation

`gh-qw` is a GitHub CLI extension for managing GitHub repositories and Git
worktrees. The canonical documentation is maintained as Markdown in this
repository; no separate documentation website is required.

- [Concept](concept/README.md) — repository and worktree model
- [CLI reference](reference/cli/README.md) — commands, flags, output, and exit statuses
- [Configuration](reference/configuration/README.md) — roots and precedence
- [Versioning](reference/versioning/README.md) — compatibility and releases
- [Compatibility](reference/compatibility/README.md) — Git and GitHub CLI requirements
- [Repository settings](reference/repository-settings/README.md) — managed settings and operational boundaries
- [Contributing](development/contributing/README.md) — development and validation
- [Architecture Decision Records](development/adr/README.md) — design history

Install the extension with `gh extension install daiksud/gh-qw`.

See the [project README](../README.md) for a quick start.
